# 영어 듣기 음원 및 평가자료 자동 제작 도구 (Listening Web Test)

영어 듣기 대본을 바탕으로 다국적 원어민 음성 합성, 기계 검수, AI 객관식 문항 출제, 국가 표준 2단 HWPX 문제지 및 **모바일 OMR 웹 응시 페이지**를 원클릭으로 생성하는 올인원 교사 지원 도구입니다.

---

## 📱 모바일 웹 응시 페이지 주요 기능
- **서버리스 완전 독립 동작**: GitHub Pages 및 오프라인 환경(`file:///`)에서 100% 실행되는 정적 웹 시험지입니다.
- **모바일 390px 반응형 인터페이스**: 스마트폰(iPhone/Galaxy) 화면에 최적화된 터치 친화적 카드형 레이아웃을 제공합니다.
- **문항별 오디오 플레이어**: 터치 친화적 재생 컨트롤 및 **재생 횟수 제한(기본 2회)** 기능을 내장했습니다.
- **5지선다 OMR 마킹**: 큼직한 탭 버튼과 하단 플로팅 응답 현황 바로 편리하게 답안을 작성할 수 있습니다.
- **즉시 자동 채점 및 해설**: 제출 즉시 100점 만점 환산 점수, 문항별 정오 뱃지, 상세 해설, 단서 문장 및 원문 대본 아코디언 토글을 제공합니다.

---

## 🛠️ 주요 도구 구성

1. **`1_처음한번_설치.bat`**: 필요한 라이브러리(edge-tts, faster-whisper, numpy, av) 자동 설치
2. **`2_웹앱_실행.bat`**: 메뉴 선택형 통합 실행기 (웹앱 시작 / 모바일 시험지 생성 / 종료)
3. **`app.py` & `index.html`**: 음원 제작, 검수, 문항 편집용 로컬 웹 대시보드
4. **`mobile_exam_generator.py`**: 정적 모바일 웹 OMR 시험지 조립 엔진
5. **`make_mobile_exam.py`**: CLI 대화형 모바일 시험지 독립 빌더
6. **`exporter.py`**: HWPX, DOCX, HTML, 음원, 자막, 모바일 웹 시험지 일괄 패키징 엔진
7. **`docs/`**: GitHub Pages 자동 배포용 정적 웹 시험지 및 샘플 음원 폴더

---

## 🚀 로컬 실행 방법

1. `2_웹앱_실행.bat`을 더블클릭합니다.
2. 콘솔 메뉴에서 원하는 번호를 선택합니다:
   - `1`: 듣기 음원 만들기 웹앱 시작 (`http://127.0.0.1:8765`)
   - `2`: 모바일 웹 응시 페이지 독립 생성기 실행
   - `3`: 종료
3. 생성된 모바일 시험지는 `docs/index.html`을 브라우저로 열어 바로 응시할 수 있습니다.
